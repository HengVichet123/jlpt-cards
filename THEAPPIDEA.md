The app is **not the curriculum. It is the palace where the curriculum is learned.**


Give the learner a place where their target knowledge lives, and use different learning methods to help them acquire it.


The user chooses what they want to learn, and the app builds a complete learning environment around that material.

### Basic idea

**Input a learning set → build a Mind Palace around it**

For example:

> Shinkanzen N2 vocabulary
> → import the vocabulary
> → the app builds the learning environment
> → reading, practice, complete list, images, lessons, tracking, etc.

The app then tracks the learner's progress through that specific set.

### Long-term vision

A teacher could give the app:

> **1,000 N3 words**

and the app would create a learning space for those 1,000 words.

The same system could work for:

* a textbook
* a vocabulary book
* a teacher's custom word list
* eventually, any personal list of words

### Why books are the realistic starting point

Generating complete supporting content for completely arbitrary word lists is currently difficult to do quickly and flexibly.

Books provide a practical, structured curriculum that we can build around first.

So the current (v92)

> **The curriculum can change. The palace stays.**

Japanese Mind Palace — Two Modes

The app should support two fundamentally different ways of learning.

1. Default Palace — Open-ended Japanese

The default app is not built around a fixed vocabulary list.

It is for people who already know some Japanese and want to keep expanding their language naturally.

The app provides:

Reading news and articles
Quizzes to discover unfamiliar words
Practice and review
Pictures and visual learning
Games / interactive activities
Content adjusted to the user's Japanese level

There is no requirement to "finish" a specific vocabulary list.

The goal is simply:

Keep expanding what you know and become more capable with Japanese.

2. Custom Palace — Targeted Learning

A user can provide a specific learning target:

A textbook
A vocabulary book
A teacher's word list
A custom collection of words

For example:

Shinkanzen N2 vocabulary → import → build a palace around it.

The app then organizes its learning tools around that specific target and tracks whether the user has actually mastered the material.

Core idea

These are not two separate apps.

They use the same underlying system:

Content → exposure → quizzes/practice → learning history → knowledge tracking

The difference is whether there is a defined target set.

Default Palace: open-ended exploration of Japanese.
Custom Palace: deliberate mastery of a specific set.

Language is an open world, so the app should not force all language learning into the "finish this list" model.
